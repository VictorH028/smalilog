# Configuración

El archivo opcional `config.toml` se busca en el directorio de trabajo. Usa `docs/config.example.toml` como plantilla y adapta `workspace` a tu entorno.

Las variables de entorno usan el prefijo `SMALILOG_`.

La configuración del servidor HTTP se controla directamente desde `smalilog server`: host, puerto, archivo, nivel de log y límites HTTP.
